OFFLINE CHAT - POORA PROJECT (Android Studio me seedha khulta hai)

Tarika A: Android Studio (laptop)
  1. Android Studio > Open > is folder ko chuno > Sync hone do
  2. Phone USB se jodo > Run

Tarika B: Bina Android Studio ke, GitHub se APK (free)
  1. github.com par account banao > New repository (Public ya Private)
  2. "uploading an existing file" se is folder ki SAARI files upload karo
     (.github folder samet, wahi structure rakhna)
  3. Upar "Actions" tab > "Build APK" > build poora hone do (3-5 min)
  4. Build par click > neeche "Artifacts" > OfflineChat-APK download karo
  5. Zip kholo, app-debug.apk phone me install karo
