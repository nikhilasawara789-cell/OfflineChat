## 📌 About The Project

OfflineChat is an Android-based chatting application designed to enable communication between users over a local Wi-Fi network without requiring an active internet connection.

The main goal of this project is to provide a simple and convenient way to exchange messages locally using Wi-Fi connectivity.

## ✨ Key Features

- 📡 Wi-Fi Based Communication
- 💬 Offline Messaging
- 📱 Android Application
- ⚡ Local Network Communication
- 🔐 Security-Related Implementation
- 🎨 User-Friendly Interface
- 🔑 Login Interface
- 📲 Android Native Development

## ⚙️ Installation & Setup

### 1. Clone Repository

```bash
git clone https://github.com/nikhilasawara789-cell/OfflineChat.git
```

### 2. Open in Android Studio

- Open Android Studio.
- Select Open Project.
- Choose the OfflineChat folder.
- Wait for Gradle Sync to complete.

### 3. Connect Android Devices

- Connect the Android devices to the same Wi-Fi network.
- Make sure the required local network permissions are enabled.
- Follow the application's connection setup.

### 4. Run Application

- Select an Android device or emulator.
- Click the Run button in Android Studio.
- Launch OfflineChat.

## 📡 How It Works

1. Users connect their devices to the same local Wi-Fi network.
2. The application uses local network communication.
3. Users establish a connection through the app.
4. Messages can be exchanged without using an internet connection.
